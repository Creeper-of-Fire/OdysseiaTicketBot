# 英文投诉面板配置与部署

本改动在保留现有中文入口的前提下，新增一个独立的英文入口面板。中文面板、已有工单和旧按钮均不受影响。

## 1. 用户侧效果

- 中文入口：按钮仍为「🔒 提交投诉」，流程与现在完全一致。
- 英文入口：按钮为「🔒 Submit a Complaint」，类型选择、详细说明、表单、二次确认、创建成功提示、工单头部和管理面板都使用英文。
- 工单语言会写入 `data/complaint_channels.json` 的 `locale` 字段；旧工单没有该字段时按中文处理。
- 英文工单的「关闭频道 → 归档 → 删除频道」**操作面板**已英文；生成的归档 HTML 仍使用中文标题/字段名。召唤身份组、召唤用户、转接工单等管理员二级面板暂保持中文（仅管理员/处理组使用，不影响外国用户提交投诉）。

## 2. 发布英文面板

更新代码并重启机器人后，在英文频道执行：

```text
/许嘉慧丨投诉管理 发布入口面板 language:English
```

在中文频道执行原来的命令（不传 `language`）即可发布/重发中文面板：

```text
/许嘉慧丨投诉管理 发布入口面板
```

> 只改 TOML 不会让旧面板变成英文。入口面板的标题、说明和按钮文案在代码里，必须用新代码 + 上面的命令发布。

## 3. TOML 新增字段

所有 `*_en` 字段都是可选的。留空时回退到对应的中文值；但英文入口的 `channel_header_en` 留空时会使用内置英文默认模板，不会回退到中文头部。

### `[templates]`

| 字段 | 说明 |
|---|---|
| `channel_header_en` | 英文工单的头部消息模板。留空使用内置英文默认模板。 |
| `form_field_format_en` | 英文字段格式，默认 `**{label}**: {value}`。 |
| `default_responsibility_notice_en` | 英文二次确认的默认责任提示。留空会显示英文「未配置」提示。 |
| `unknown_type_label_en` | 英文回退类型名，默认 `Unknown`。 |

### `[role_groups.*]`

| 字段 | 说明 |
|---|---|
| `label_en` | 身份组英文名，用于类型选择页和确认页的「Visible team」。 |

### `[[types]]`

| 字段 | 说明 |
|---|---|
| `label_en` | 类型英文名。 |
| `description_en` | 类型英文简述（下拉菜单与详情页）。 |
| `detail_description_en` | 选中类型后的英文详细说明。 |
| `responsibility_notice_en` | 该类型的英文责任/敏感提示，优先级高于 `default_responsibility_notice_en`。 |
| `header_blocks_en` | 英文工单头部的通知行；留空复用 `header_blocks`。 |

### `form_fields`

| 字段 | 说明 |
|---|---|
| `label_en` | 表单字段英文名。 |
| `placeholder_en` | 英文输入提示。 |

## 4. 配置示例

完整模板见 [`docs/complaint-en.example.toml`](complaint-en.example.toml)。核心写法：

```toml
[templates]
channel_header_en = """\
📌 {complainant_mention} submitted a complaint
🎫 Ticket number: #{ticket_number}
📋 Complaint type: {type_emoji} {type_label}
📅 Time: {timestamp}
{form_section}
{custom_section}"""

default_responsibility_notice_en = """\
⚠️ **Please do not submit sensitive information** (private chat screenshots, doxxing information, etc.).
Please make sure the content is appropriate for the selected handling team."""

[role_groups.total_admin]
label = "总管理"
label_en = "Administrators"
role_ids = [0]  # TODO: 填真实角色 ID

[[types]]
id = "personal_attack"
label = "人身攻击投诉"
label_en = "Personal Attack"
emoji = "⚔️"
description = "针对人身攻击行为"
description_en = "For personal attacks"
detail_description = "请提供被投诉人、事件经过和证据。"
detail_description_en = "Please provide the accused user, what happened, and any evidence."
target_role_groups = ["total_admin"]
responsibility_notice_en = "This ticket is visible to the Administrators team."
header_blocks = ["📢 通知 **总管理** {@total_admin} 协助处理"]
header_blocks_en = ["📢 Notify **Administrators** {@total_admin}"]
form_fields = [
    { key = "target", label = "被投诉人", label_en = "Accused user", placeholder = "请输入用户名或ID", placeholder_en = "Enter a username or ID", style = "short", required = true },
    { key = "description", label = "详细描述", label_en = "Details", placeholder = "请描述事件经过", placeholder_en = "Describe what happened", style = "paragraph", required = true },
    { key = "evidence", label = "证据链接（可选）", label_en = "Evidence links (optional)", placeholder = "消息链接、截图链接", placeholder_en = "Message or screenshot links", style = "short", required = false },
]
```

## 5. 作者侧部署步骤

1. 合并代码（或应用 patch），重新构建并重启机器人。
2. 在现有 `data/complaint_<服务器ID>.toml` 中补充 `*_en` 字段。**不要编造频道 ID、角色 ID**，使用服务器真实值。
3. 执行 `/许嘉慧丨投诉管理 重载配置` 使 TOML 生效（代码更新仍需重启）。
4. 在英文频道执行 `/许嘉慧丨投诉管理 发布入口面板 language:English`。
5. 用普通用户账号走一遍：英文入口 → 类型选择 → 表单 → 确认 → 进入工单，确认头部、管理面板和关闭归档均为英文。

## 6. 兼容性

- 旧的中文入口按钮 `custom_id = complaint:entry`、管理面板、归档和删除按钮的 `custom_id` 均保持不变。
- 旧工单的 `complaint_channels` 数据没有 `locale` 字段，加载时默认为 `zh`。
- 当前仓库代码中 `requires_confirm` 已移除，所有类型统一走二次确认；附件指南里的该字段不会再生效。
- 指南未列出但当前代码支持的字段：`pin_role_groups`、`notify_channel_id`、`notify_message`、类型级 `category_id` / `archive_channel_id`。编辑配置时应以仓库代码为准。

```text
你好，我这边服务器有较多英文用户，想给投诉系统加一个英文入口面板，同时保留中文面板。

我基于当前 main 做了一版改动，主要包含：
1. 入口面板支持 language 选项，新增 English 持久化按钮；
2. 类型选择、详情、表单、二次确认、创建提示、工单头部、管理面板/归档/删除流程支持英文；
3. TOML 新增可选字段：templates.channel_header_en / form_field_format_en /
   default_responsibility_notice_en / unknown_type_label_en，
   role_groups.*.label_en，types.*.label_en / description_en /
   detail_description_en / responsibility_notice_en / header_blocks_en，
   form_fields[].label_en / placeholder_en；
4. 旧面板、旧工单和旧 custom_id 保持兼容，未配置英文时回退中文。

部署时需要：合并代码并重启 → 在现有 TOML 补英文文案和真实 Discord ID →
/重载配置 → 在英文频道执行 /发布入口面板 language:English。

具体字段和示例见 docs/英文投诉面板配置.md 和 docs/complaint-en.example.toml。
```
