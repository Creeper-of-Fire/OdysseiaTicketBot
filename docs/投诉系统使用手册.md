## 系统概述

投诉系统是一个基于 Discord 的私密投诉与反馈平台，为社区成员提供安全、便捷的沟通渠道。

**核心特性：**

- 隐私保护 —— 每份投诉自动创建独立私密频道，仅投诉人和相关管理可见
- 类型化投诉 —— 预设多种投诉类型，每种类型有专属表单和处理团队
- 灵活管理 —— 管理组可召唤额外身份组或用户加入讨论
- 完整归档 —— 频道关闭时自动导出为离线 HTML 归档文件

## 用户指南：提交投诉

### 第一步：找到投诉入口

在服务器中找到包含「投诉中心」面板的频道，点击下方的 **「提交投诉」** 按钮。

```
📋 投诉中心
┌──────────────────────────────────────┐
│ 如果你在社区中遇到了问题...           │
│                                      │
│ 📌 提交流程                           │
│ 1. 点击下方「提交投诉」按钮           │
│ 2. 选择投诉类型                       │
│ 3. 填写投诉表单                       ││ 4. 系统将为你创建一个私密频道          │
│                                      │
│ 🔒 隐私保护                           │
│ 仅你本人和对应管理组成员可见           │
└──────────────────────────────────────┘
          [ 提交投诉 ]
```

### 第二步：选择投诉类型

点击按钮后，系统会弹出类型选择菜单。每种类型都有 emoji 标识和简要说明：

| 类型 | Emoji | 说明 | 需要二次确认 |
|------|-------|------|:----------:|
| 人身攻击投诉 | ⚔️ | 针对人身攻击行为进行投诉 | 是 |
| 答疑判罚投诉 | ❓ | 对答疑组的某次判罚有意见 | 是 |
| 管理组判罚投诉 | 🔨 | 对自己或他人的某次判罚有意见 | 是 |
| 社区建设建议 | 🏗️ | 对社区建设提出建议 | 否 |
| 制度/流程质询 | 📜 | 对社区制度或流程提出质询 | 否 |
| 社区不良内容投诉 | 🚫 | 举报社区中的不良内容 | 否 |
| 举报商业化内容 | 💰 | 举报商业化行为 | 是 |
| 弹劾管理组 | ⚖️ | 对管理组发起弹劾 | 是 |
| 其他 | 📝 | 其他类型的投诉或反馈 | 否 |

选择后，系统会显示该类型的详细说明。点击 **「确认」** 继续，或 **「取消」** 返回。

### 第三步：填写投诉表单

确认类型后，系统会弹出表单弹窗。不同类型有不同的表单字段，示例如下：

**人身攻击投诉：**

| 字段 | 格式 | 是否必填 | 示例 |
|------|------|:--------:|------|
| 被投诉人 | 短文本 | 必填 | @某用户 |
| 详细描述 | 长文本 | 必填 | 事件经过描述... |
| 证据链接（可选） | 短文本 | 选填 | 消息链接、截图链接 |

**答疑判罚投诉：**

| 字段 | 格式 | 是否必填 |
|------|------|:--------:|
| 相关判罚 | 短文本（最多 200 字符） | 必填 |
| 你的意见 | 长文本（最多 1000 字符） | 必填 |

> 短文本字段最多可输入 200 个字符，长文本字段最多可输入 1000 个字符。表单会在 5 分钟后超时。

### 第四步：确认提交（部分类型）

对于标记为「需要二次确认」的类型（如人身攻击、弹劾等），提交表单后会再弹出一次确认：

```
⚠️ 确认提交
┌──────────────────────────────────────┐
│ 你即将提交一份 ⚔️ 人身攻击投诉       │
│                                      │
│ 提交后系统将：                        │
│ • 创建一个仅你和对应管理可见的私密频道 │
│ • 通知相关管理组成员加入处理           │
│ • 你可以在频道中与管理组直接沟通       │
│                                      │
│ 确定要继续吗？                        │
└──────────────────────────────────────┘
    [ 确认提交 ]  [ 取消 ]
```

点击 **「确认提交」** 后，系统自动创建私密投诉频道。

### 第五步：进入投诉频道

频道创建成功后，你会收到一条包含频道链接的确认消息。点击即可进入你的专属投诉频道。

频道命名格式为 `工单-{编号}`，例如 `工单-1`、`工单-2`。

频道首条消息会包含你的投诉详情和表单内容，相关管理组会自动收到通知。

## 管理指南：投诉频道管理

每个投诉频道创建时都会附带一个 **「频道管理面板」**，提供以下管理操作：

```
🛠️ 频道管理面板
┌──────────────────────────────────────┐
│ • 📢 召唤身份组（仅管理组可用）        │
│   邀请管理组身份组加入本频道           │
│                                      │
│ • 👤 召唤用户（仅管理组可用）          │
│   邀请特定用户加入本频道               │
│                                      │
│ • 🗑️ 关闭频道                        │
│   如果处理完毕，可以归档并关闭本投诉频道│
└──────────────────────────────────────┘
 [召唤身份组] [召唤用户] [关闭频道]
```

### 召唤身份组

仅管理组可用。将指定身份组的所有成员添加到频道权限中，使其可以查看和发送消息。

> 注意：为避免骚扰大量成员，召唤身份组时不会发送 @mention 通知。如有需要，请手动 @ 相关人员。

操作流程：选择身份组 → 确认 → 完成。

### 召唤用户

仅管理组可用。邀请特定用户加入当前投诉频道，每次最多选择 10 位用户。

被选中的用户将获得频道查看和发送权限，并会收到加入通知。

操作流程：选择用户 → 确认 → 完成。

### 关闭频道

投诉人和管理组均可发起。点击后进入归档流程（详见下一节）。

如果管理面板消息丢失或已过期，管理员可以使用 `/许嘉慧丨投诉管理 重发管理面板` 重新发送管理面板。

## 管理指南：归档与关闭

### 归档流程

关闭频道需经过以下步骤：

**1. 发起归档**

管理员在管理面板点击 **「关闭频道」**。

**2. 确认归档（两步确认）**

```
⚠️ 确认归档
┌──────────────────────────────────────┐
│ 由 @某用户 发起                       │
│                                      │
│ 此操作将对本投诉频道执行归档：         │
│ • 导出频道内所有消息为归档文件并保存   │
│ • 归档文件将发送至归档频道永久保存     │
│ • 归档完成后，可选择删除本频道         │
│                                      │
│ ⚠️ 归档后频道内容将无法恢复            │
└──────────────────────────────────────┘
    [ 归档频道 ]  [ 取消 ]
```

仅管理员可以确认归档。

**3. 生成归档**

系统自动将频道内所有消息导出为 DiscordChatExporter 风格的 HTML 归档文件，包含：

- 所有消息内容与时间戳
- 用户头像
- 嵌入消息（Embed）
- 图片附件（离线保存）
- Markdown 渲染（粗体、斜体、代码块等）

归档文件发送至配置的归档频道后，会显示归档完成消息及跳转链接。

**4. 删除频道（可选）**

归档完成后可选择删除频道。点击 **「确认删除频道」** 后会有 5 秒倒计时，倒计时期间可随时取消：

```
⏳ 即将删除频道... 5 秒
     [ 取消 ]
```

倒计时结束后，频道将被永久删除。

管理员也可以使用 `/许嘉慧丨投诉管理 强制归档` 直接在投诉频道内发起归档。

## 管理指南：斜杠命令一览

所有投诉管理命令位于 `/许嘉慧丨投诉管理` 命令组下，仅管理员可用。

| 命令 | 说明 | 使用场景 |
|------|------|----------|
| `发布入口面板` | 在当前频道发布投诉入口面板 | 首次部署或需要重新发布入口时 |
| `重载配置` | 从 TOML 文件重新加载投诉配置 | 修改配置文件后使其生效 |
| `下载配置` | 下载当前服务器的 TOML 配置文件 | 需要编辑配置时先下载 |
| `上传配置` | 上传新的 TOML 配置文件覆盖当前配置 | 编辑完成后上传新配置 |
| `编辑模板` | 弹窗编辑投诉频道消息模板 | 快速修改模板内容 |
| `重发管理面板` | 在当前投诉频道重新发送管理面板 | 原管理面板丢失或按钮失效时 |
| `强制归档` | 在当前投诉频道直接发起归档 | 需要跳过管理面板直接归档时 |

## 管理指南：配置管理

投诉系统使用 TOML 格式的配置文件，存储路径为 `data/complaint_{服务器ID}.toml`。

### 编辑方式

有以下三种方式编辑配置：

**方式一：下载 → 编辑 → 上传（推荐）**

1. 使用 `/许嘉慧丨投诉管理 下载配置` 下载当前配置文件
2. 用文本编辑器修改下载的 TOML 文件
3. 使用 `/许嘉慧丨投诉管理 上传配置` 上传修改后的文件

**方式二：弹窗编辑模板**

使用 `/许嘉慧丨投诉管理 编辑模板` 打开一个包含完整 TOML 内容的弹窗编辑器。

> 注意：当配置文件超过 4000 字符时，弹窗无法承载，需改用下载-编辑-上传方式。

**方式三：直接编辑服务器文件**

在服务器文件系统中直接编辑 TOML 文件，然后使用 `/许嘉慧丨投诉管理 重载配置` 使其生效。

### 配置文件过大时

当配置文件超过 4000 字符时：
- 「编辑模板」命令将提示配置过大，阻止弹窗编辑并还原前缀
- 请使用下载-编辑-上传方式进行修改

## 配置文件详解

### 完整配置结构

```toml
# 服务器基础设置
[guild]
category_id = 0          # 投诉频道所在的 Discord 分类 ID
archive_channel_id = 0   # 归档文件发送目标频道的 ID

# 全局归档设置
[global]
archive_concurrent_limit = 2   # 同时进行的最大归档数
media_budget_mb = 32            # 离线媒体总预算 (MB)，0 = 无限制
single_image_max_mb = 0        # 单张图片最大体积 (MB)，0 = 无限制

# 消息模板
[templates]
channel_header = """..."""         # 频道头部消息模板
form_field_format = "**{label}**：{value}"  # 表单字段显示格式

# 身份组定义
[role_groups.{组ID}]
label = "显示名称"
role_ids = [0]  # Discord 角色 ID 列表

# 投诉类型定义（数组，可添加多个）
[[types]]
id = "唯一标识"
label = "显示名称"
emoji = "📋"
description = "简要说明"
detail_description = """详细说明"""
requires_confirm = true/false
target_role_groups = ["组ID"]
header_blocks = ["自定义通知行"]
form_fields = [{ ... }]
category_id = 0            # 可选：本类型专属的分类频道 ID，0 = 使用 [guild].category_id
archive_channel_id = 0     # 可选：本类型专属的归档频道 ID，0 = 使用 [guild].archive_channel_id
```

### 按类型覆盖分类与归档频道

`[[types]]` 段中的 `category_id` 和 `archive_channel_id` 为可选项，默认值为 `0`，表示沿用 `[guild]` 中对应字段。设置后，该类型的工单会创建到对应分类下，归档文件会发送到对应归档频道，便于按类型分流到不同管理组。

> 工单编号计数器始终在 `[guild].archive_channel_id` 中维护（通过 `[投诉计数]已发布N` 消息），是全服共享的递增序列，不会因 `archive_channel_id` 按类型覆盖而分别计数。

### 频道头部模板宏

`channel_header` 模板支持以下宏：

| 宏 | 替换为 |
|----|--------|
| `{complainant_mention}` | 投诉人的 @mention |
| `{type_label}` | 投诉类型名称 |
| `{type_emoji}` | 投诉类型 emoji |
| `{timestamp}` | 提交时间 |
| `{ticket_number}` | 工单编号 |
| `{form_section}` | 所有表单字段的格式化文本 |
| `{custom_section}` | header_blocks 渲染后的自定义内容 |

### header_blocks 宏

每个投诉类型的 `header_blocks` 中的每一行支持以下宏：

| 宏 | 替换为 |
|----|--------|
| `{@组ID}` | 该身份组中所有角色的 @mention（空格分隔） |
| `{type_label}` | 投诉类型名称 |
| `{type_emoji}` | 投诉类型 emoji |
| `{ticket_number}` | 工单编号 |

### 表单字段定义

每个投诉类型最多可定义 **5 个** 表单字段：

```toml
form_fields = [
    { key = "字段键名", label = "显示名称", style = "short", required = true, placeholder = "提示文字" },
]
```

| 属性 | 说明 |
|------|------|
| `key` | 字段唯一标识，用于内部存储 |
| `label` | 表单中显示的字段名 |
| `style` | `short`（短文本，最多 200 字符）或 `paragraph`（长文本，最多 1000 字符） |
| `required` | 是否必填 |
| `placeholder` | 输入框提示文字 |

## 权限说明

### 管理员判定

满足以下任一条件即为管理员：

- 用户 ID 在 `ADMIN_USER_IDS` 中
- 用户拥有 `ADMIN_ROLE_IDS` 中任一角色

### 权限矩阵

| 操作 | 普通用户 | 投诉人 | 管理员 |
|------|:--------:|:------:|:------:|
| 提交投诉 | ✅ | ✅ | ✅ |
| 关闭/归档投诉频道 | — | — | ✅ |
| 确认归档 | — | — | ✅ |
| 删除频道 | — | — | ✅ |
| 召唤身份组/用户 | — | — | ✅ |
| 使用所有斜杠命令 | — | — | ✅ |

### 频道可见性

投诉频道创建时自动设置以下权限：

- `@everyone`：拒绝查看、发送、读取历史
- 机器人：完全权限
- 投诉人：允许查看、发送、读取历史、上传附件
- 目标管理组角色：允许查看、发送、读取历史、上传附件

## 常见问题

### Q: 投诉入口面板的按钮点击没有反应？

入口面板使用持久化按钮，机器人重启后仍然有效。如果无反应，请确认机器人在线运行。如有必要，管理员可以重新运行 `发布入口面板` 命令。

### Q: 管理面板的按钮失效了怎么办？

管理员可在对应投诉频道内使用 `/许嘉慧丨投诉管理 重发管理面板` 重新生成管理面板。

### Q: 工单编号是怎么生成的？

工单编号通过归档频道中的计数器消息生成。首次使用前，管理员需在归档频道中手动发送 `[投诉计数]已发布0` 进行初始化。

### Q: 归档文件包含什么内容？

归档文件为 DiscordChatExporter 风格的 HTML 文件，包含频道内所有消息、用户头像、嵌入消息、图片附件和 Markdown 渲染。当媒体内容较大时，可能生成 ZIP 压缩包。

### Q: 弹劾管理组的投诉，被弹劾者能看到吗？

不能。弹劾类型仅通知超级管理员，由超级管理员决定是否转交监察组处理。被弹劾的管理不会收到通知。

### Q: 修改配置后需要重启机器人吗？

不需要。修改 TOML 配置文件后，使用 `/许嘉慧丨投诉管理 重载配置` 命令即可热加载，无需重启。

### Q: 配置文件太大，弹窗编辑器打不开怎么办？

当配置文件超过 4000 字符时，请使用下载-编辑-上传方式：
1. `/许嘉慧丨投诉管理 下载配置` 下载文件
2. 在本地编辑
3. `/许嘉慧丨投诉管理 上传配置` 上传修改后的文件
