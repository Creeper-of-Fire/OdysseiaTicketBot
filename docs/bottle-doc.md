# 漂流瓶系统使用手册(管理员)

> 受众:discord 服务器管理员(通过 bot 命令操作 toml)
> 不需要写代码,所有变更都通过 `/上传配置` 完成

---

## 这是什么

漂流瓶是给社区成员用的匿名感互动功能:把心愿扔进海里,别人随机打捞,可以认领 / 跳过。认领后,作者确认完成就算结束。每条瓶子有海里过期时间和认领时限,超时自动回收。

---

## 字段说明

所有字段**必填**,无默认。漏一个就启用失败。

| 字段 | 类型 | 说明 |
|---|---|---|
| `max_held_per_user` | int ≥ 1 | 单个用户同时持有(已认领未完成)的瓶子上限。建议 3-5。 |
| `bottle_lifetime_days_default` | int ≥ 1 | 瓶子在海里漂多久后自动作废(天)。发布者可在发布 modal 里临时覆盖。 |
| `claim_deadline_days_default` | int ≥ 1 | 认领后多久不完成,瓶子自动回海里(天)。发布者可在发布 modal 里临时覆盖。 |

> **不需要配置 panel 频道**——bot 通过 `interaction.channel_id` 自动知道用户从哪个频道 / 哪条 panel 消息触发,所以允许在任意频道发任意数量的 panel。

---

## 完整示例 toml

把下面的内容复制成 `data/bottle_{你的guild_id}.toml`,然后改 ID:

```toml
max_held_per_user = 3
bottle_lifetime_days_default = 14
claim_deadline_days_default = 7
```

guild_id 是你的服务器 ID。bot 命令发在哪个服务器,就把这个服务器 ID 填进去。

## 上传 / 修改流程

### 首次上传

1. 在本服务器任意频道运行 `/漂流瓶管理  下载配置`
2. 如果 bot 返回 "❌ 当前 bottle 还没有配置文件",说明是首次
3. 按上面的示例 toml 复制成 `bottle_{guild_id}.toml`,填好字段
4. 运行 `/漂流瓶管理  上传配置`(可省略 `hash_str`)
5. bot 会要求二次确认(因为没有现有版本可校验)
6. 点 "确认写入" 后配置生效

### 后续修改

1. `/漂流瓶管理  下载配置` → 拿到当前 toml + 当前 SHA-256(前 12 字符)
2. 本地修改 toml 文件(用文本编辑器)
3. `/漂流瓶管理  上传配置`
   - `toml_file`:填你修改后的 toml 文件
   - `hash_str`:填你下载时拿到的 SHA-256 前 12 字符
4. bot 校验 SHA-256 → 通过则写入,否则拒绝并提示重新下载

### 只想看当前哈希

`/漂流瓶管理  查看配置哈希`

---

## SHA-256 是干什么的

多人协作时,防止你改了版本,但别人在你之前已经上传了新版——导致你的修改覆盖别人。SHA-256 是文件指纹,上传时带上你下载时拿到的版本号,bot 比对:

- **一致** → 你的修改基于当前最新版本 → 通过
- **不一致** → 你手里的版本已过期 → 拒绝,提示重新下载

不写 hash_str 不行吗?本地已有配置时**必须**带,bot 不接受盲写(防覆盖别人)。

## Panel 按钮说明

bot 在调用 `/漂流瓶管理  发布面板` 的**当前频道**发一条常驻消息,5 个按钮:

| 按钮 | 功能 |
|---|---|
| 📮 发布 | 弹 modal,填完二次确认后扔进海里 |
| 🎣 打捞 | 从海里随机抽一个,只给你看(别人可能同时被 DM 到同一个瓶子,只有"认领"才锁定) |
| 📤 我发的 | 按状态展示你发布的所有瓶子 |
| 🎣 我捞的 | 按状态展示你认领 / 完成的所有瓶子 |
| ⚙️ 配置 | 提示文字,引导用 toml 命令 |

所有按钮的反馈消息都是 ephemeral(频道内只对当前用户可见),不会刷屏。

## 常见问题

### Q: 我改了 toml,bot 没生效?

按上传流程跑一遍即可。**bot 启动时会读一次 toml**;之后任何修改都得通过 `/上传配置`,bot 会自动重新加载缓存。

### Q: 多个服务器都需要配置吗?

是的,每个 guild 一份 `bottle_{guild_id}.toml`,互不影响。

### Q: 缺字段会怎样?

bot 启动时检测到任何 guild 的 toml 缺字段 → 该 guild 的 bottle 功能禁用,日志报错,其他 guild 不受影响。其他功能(投诉、许愿、core、temp)都正常。

### Q: 我可以发多个 panel 吗?

可以。在任意频道跑 `/漂流瓶管理  发布面板` 都会发一条新的 panel。它们共享同一份数据,用户点任意 panel 都能交互。bot 通过 `interaction.channel_id` 自动知道用户从哪个 panel 触发的,不需要任何配置。

### Q: 实名制是什么意思?

发布者公开显示(`<@作者id>`),捞到的人也能看到 ta 是谁。**没有匿名功能**——这是有意的产品决定(避免匿名带来的骚扰问题,也方便"交朋友"类心愿的实现)。
